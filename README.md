# Ember & Olive — сайт ресторана авторской кухни

Демонстрационный проект веб-студии: премиальный одностраничный сайт ресторана
с интерактивным 3D-блюдом, меню по категориям, галереей и формой бронирования.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

## Структура

| Файл | Что внутри |
| --- | --- |
| `src/data.js` | Весь контент: меню, цены, популярные блюда, галерея, история, контакты |
| `src/App.jsx` | Секции сайта, карточка блюда, лайтбокс, форма бронирования |
| `src/three/dishScene.js` | 3D-сцена: свет, окружение для отражений, тени, загрузка GLB и программный WebGL |
| `src/three/framing.js` | Чистые расчёты нормализации 3D-модели и кадрирования камеры |
| `src/three/framing.test.js` | Модульные тесты кадрирования и масштабирования (`node:test`) |
| `src/three/proceduralDish.js` | Запасное процедурное блюдо на случай отсутствия GLB |
| `src/three/noise.js` | Шум для процедурных текстур и геометрии |
| `src/lib/booking.js` | Валидация формы и отправка заявки |
| `src/styles.css` | Дизайн-токены и стили |

## 3D-модель блюда

В проект уже добавлена 3D-модель `public/models/restaurant-dish.glb` — **Iridescent Dish with Olives**
(Wayfair / Khronos Group glTF Sample Assets, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).

Вы можете заменить `public/models/restaurant-dish.glb` на любую другую модель — она подхватится
автоматически, отцентрируется и отмасштабируется под сцену. Если файла нет или он повреждён,
показывается процедурная версия без ошибок в консоли. Если у устройства нет WebGL — фотография блюда.

Рекомендации к модели: до 5–6 МБ, PBR-материалы, блюдо лежит в плоскости XZ, «верх» — ось +Y.

## Бронирование

По умолчанию онлайн-бронь **не подключена**: форма проверяет данные и честно сообщает
гостю, что заявка не отправлена, предлагая позвонить. Чтобы подключить систему бронирования,
создайте `.env` по образцу `.env.example`:

```
VITE_BOOKING_ENDPOINT=https://example.com/api/bookings
```

На этот адрес уходит `POST` с JSON:

```json
{ "name": "Анна", "phone": "+79000000000", "date": "2026-11-21", "time": "19:30", "guests": 2, "comment": "", "source": "website" }
```

Ответ 2xx показывается гостю как «Заявка отправлена», любой другой — как ошибка с предложением позвонить.

## Что заменить перед показом реальному ресторану

- Название, адрес, телефон, email, часы работы — `src/data.js` (`contacts`), а также `index.html` (title, description).
- Блюда, цены, вес, аллергены — `src/data.js` (`menu`).
- Имя шефа и история — `src/data.js` (`timeline`) и цитаты в `src/App.jsx`.
- Фотографии — ID снимков Unsplash в `src/data.js`; свои фото можно положить в `public/` и заменить функцию `img()`.
